magpie 本地语义搜索

2026-08-21 ·笔记 ·1805 字 ·约 5 分钟 ·阅读 次
RustTauri工具

星标过的仓库再也没打开过第二次，截图知道长什么样却翻不到，书签埋在几层文件夹里，这些东西的共同点是存的时候很顺手、找的时候全靠运气。
喜鹊爱叼亮闪闪的东西回窝，然后忘了放哪儿，所以叫 magpie。按一下 Alt+Space，把还记得的那点描述打进去，或者直接丢一张图进去，回车。
本地跑，不联网，不扫全盘。

三个源

Tab 在三个源之间切。

本地文件——你手动加进来的目录，里面每个文件都能按名字找到；认识的格式连内容一起进全文索引。约八十种纯文本与代码格式整篇读进去，PDF 走 pdf-inspector 抽文字，docx/xlsx/pptx 拆出文本部分，剩下的视频、压缩包、二进制按文件名索引。图片单独走视觉模型。
GitHub 星标——贴一个不需要任何 scope 的 token，整份星标列表同步下来：名字、描述、topics，加上完整 README。取消星标能识别，README 拉取带 ETag，只有内容真变了才重新嵌入。每行显示最后推送时间，荒废的项目一眼能看出来。
浏览器书签——直接读本地的书签文件，不走浏览器 API、不需要登录。Chromium 系的按磁盘上的 profile 布局自动发现，Chrome、Edge、Brave、Vivaldi、Arc 以及各种小众分支都认，加上 Firefox，所有 profile 一起读。

检索

关键词和语义各自召回一路，再按名次融合。

关键词那路是 SQLite 的 FTS5，BM25 排序；语义那路是本地跑的 multilingual-e5-small，384 维。两路各取前五十条，交给倒数排名融合。
选融合而不是加权求和，是因为 BM25 的分数和余弦相似度不是一个量纲，直接加权等于拍脑袋定系数，换个语料就得重调。倒数排名融合只吃名次，两路都靠前的会被抬上来，只在一路出现的也不会被埋掉。余弦值仍然有用，但只以 0.005 的权重叠上去，作用是破平局，不是主导排序。
跨语言是白送的。e5 是多语言模型，中文查询能命中英文 README 和代码注释，反过来也行，一百多种语言。
长内容切块，每块约 1600 字符、重叠 200 字符，一块一个向量，一个文件最多 128 块。检索时一个文件按它最好的那一块算分，所以一句话埋在第一百页里也捞得出来，README 很长的仓库也不会因为整体稀释而沉底。切块优先在换行处断，不硬切在词中间。
向量不是每次查询去库里读，是全部常驻内存。分块之后一次按键要读几十 MB，边打字边查撑不住。L2 归一化之后余弦就是点积，几万块全量暴力算是十几毫秒的事，召回率 100%，省掉一整套近似索引。真到撑不住那天，sqlite-vec 落进同一个文件就行。
模型没就绪也能用。查询向量是可空的，没有就只走关键词那一路。首次启动要下大约 700 MB 模型，这段时间搜索照常出结果，不是转圈等。

图片

图片用 SigLIP 2 嵌入，文字和图片在同一个空间里，所以两个方向都通。

文字找图——打「海边日落」，或者任何语言的同义描述，匹配的照片和别的结果一起排出来，带缩略图。
图找图——把图拖进面板、粘贴一张截图，或者点选图按钮，返回最相似的若干张，带余弦相似度百分比。

这块没用现成的封装。fastembed 的 ImageEmbedding 对三维输出默认按 CLS token 池化，而 SigLIP 用的是 MAP head、根本没有 CLS token，套上去出来的向量是错的。所以这一层自己持有 ONNX session、自己做预处理和输出选择。
图片向量上带着模型标识，换了模型或者换了权重文件，旧向量自动作废重算，不会留下两个空间里的向量混在一起比大小。损坏读不出来的图片会打一个零维标记，下次不再重试。

只读你指定的目录

这条是靠结构保证的，不是靠承诺。

magpie 只索引你显式添加的目录，指向你的工作目录，别的地方一个字节都不会读。目录内递归，但 .gitignore 规则照样生效（哪怕那个目录不是 git 仓库），隐藏文件跳过，符号链接不跟出所选目录。加目录的时候会挡住嵌套和重复。
索引就是用户目录下的一个 SQLite 文件。嵌入模型走 ONNX 本地跑，一次性下载完之后整个东西离线可用。书签直接读本地文件。没有任何东西发出去。
设置里能看到到底索引了哪些目录，删掉一个，它的文件记录、全文索引、向量一起抹掉。每个目录和星标索引都有单独的重建按钮。

索引是增量的：启动时、手动刷新、以及每三十分钟的定时器，各扫一遍新增、修改和删除。mtime 和大小都没变的文件直接跳过。

限制

扫描 PDF 和截图里的文字现在读不出来，那种 PDF 只能按文件名找到，OCR 还没做。
没有预览面板，命中之后只能开出去看。
macOS 的包没签名也没公证，装的时候要多一步。
向量是暴力算的，几万块没问题，真堆到几十万得换检索结构。
Twitter 的喜欢想做，但只能走数据导出的归档文件，官方 API 现在要钱。

代码是 MIT，Rust 核心在 core/，Tauri 壳很薄，前端就一个窗口。起因是星标列表只能按名字搜，而人记得住的通常是「那个用 Rust 写的、干什么用的东西」，偏偏就是想不起来叫什么。现在把那句话打进去能出来，暂时就够用了。
